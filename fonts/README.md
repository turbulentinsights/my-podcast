# MiSans 字体来源与授权

本网站使用小米 MiSans。现有源文件为 MiSans Regular、Bold、Light 的 WOFF2；字形设计未修改。生产构建仅对 Regular / Bold 做字符子集裁剪，减少网络传输；Light 不发布。

- 官方字体网站：https://hyperos.mi.com/font/
- 官方常见问题：https://hyperos.mi.com/font/en/faq/
- 官方许可协议：本目录 `LICENSE-MiSans.pdf`，原始文件来自 https://hyperos.mi.com/font-download/MiSans%E5%AD%97%E4%BD%93%E7%9F%A5%E8%AF%86%E4%BA%A7%E6%9D%83%E8%AE%B8%E5%8F%AF%E5%8D%8F%E8%AE%AE.pdf

原始字体随本网站源码保留，仅用于网站构建；字体本身不适用代码依赖的 MIT / BSD 许可。构建工具保留字体版权、商标和授权元数据。不单独销售或发布字体包。
